Debounce.js
function debounce(fn, delay = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}
// run only after typing stops
Meaning: every keystroke cancels the old timer and starts a new one, so the real function runs once after 300 ms of silence - one API call instead of one per letter.
